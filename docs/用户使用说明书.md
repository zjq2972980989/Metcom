> 参数已改为 **配置文件 + 命令行** 形式；GRIB2 数据 **直接读取**，无需任何
> 预转换。

> 结果与 MATLAB 原版输出**逐位一致**（ERA5 达机器精度 3.8e-11），评估结果
> 与 MATLAB 评估 CSV **逐位一致**。

## 1. 软件概述

METCOM（Meteorological reanalysis data Computation）基于多源再分析气象资料
反演**天顶对流层延迟（ZTD）**与**大气可降水量（PWV）**，包含五个按操作顺序
编号的模块：

| Python 模块           | CLI 子命令                            | 原 MATLAB 模块                       | 功能                                                     |
| --------------------- | ------------------------------------- | ------------------------------------ | -------------------------------------------------------- |
| `metcom.gridgen`    | `metcom gridgen`                    | `01_MakeGrdText`                   | 格点文件生成（DEM 裁剪/行政掩膜 → 正高/椭球高格点 txt） |
| `metcom.downloader` | `metcom download`                   | `02_Downloader`                    | ERA5 再分析数据批量下载（CDS API，支持 IDM/断点续传）    |
| `metcom.retrieval`  | `metcom retrieve`                   | `03_DataProcessing`（5 个 .mlapp） | 五种再分析资料反演 ZTD/PWV，统一框架                     |
| `metcom.timeinterp` | `metcom timeinterp`                 | `04_TimeInter`                     | 时间维度插值（6h → 1h 等）                              |
| `metcom.evaluation` | `metcom evaluate` / `metcom plot` | `05_AnaEvaluationPlot`             | 与参考数据（武大 GMET）对比评估 RMSE/Bias 并绘图         |

支持的五种再分析数据：

| 数据源   | 提供机构   | 空间分辨率     | 时间分辨率 | 数据格式          | 读取方式 |
| -------- | ---------- | -------------- | ---------- | ----------------- | -------- |
| CMA-MESO | 中国气象局 | 0.03°         | 3h         | GRIB2（21 层）    | 直读     |
| CRA40    | 中国气象局 | 0.25°         | 6h         | GRIB2（前 37 层） | 直读     |
| CRA V1.5 | 中国气象局 | 0.10°         | 1h         | GRIB2（前 37 层） | 直读     |
| ERA5     | ECMWF      | 0.25°         | 1h         | NetCDF（37 层）   | 直读     |
| MERRA2   | NASA       | 0.5°×0.625° | 6h         | NetCDF（42 层）   | 直读     |

## 2. 环境要求与安装

### 2.1 环境要求

- 操作系统：Windows 10/11（64 位）；Linux/macOS 理论可用（IDM 下载除外）
- Python：≥ 3.9
- 内存：建议 16 GB 及以上（全球尺度再分析场单时次约 1~5 GB）
- 磁盘：原始再分析数据较大，建议预留 50 GB 以上

### 2.2 安装步骤

```bash
cd METCOM_ver3.1_python
pip install -r requirements.txt           # 核心依赖（含 cfgrib）
pip install matplotlib cartopy geopandas   # 绘图功能（可选）
pip install -e .                           # 安装 metcom 命令（可选，也可用 python -m metcom.cli）
```

核心依赖：numpy / pandas / scipy / xarray / netCDF4 / h5py / pyyaml / click /
joblib / tqdm / requests / cdsapi / cfgrib。

### 2.3 GRIB 直读运行时（已内嵌，无需额外安装）

包内 `metcom/libs/eccodes-jpeg/` 内嵌了一套从原转换工具（cfgribTrans）提取
的完整 eccodes 运行时——**eccodes C 库 2.42.0（含 JPEG2000/Jasper 解码器）+
纯 Python 绑定 2.37.0 + 10 个 DLL**。首次读取 GRIB 时由
`metcom.retrieval.eccodes_backend` 自动启用，无需任何手工配置。

- pip 版 eccodes 轮子无 JPEG2000 解码器，CRA40/CMA-MESO 直读依赖上述内嵌
  运行时，**请不要 pip install eccodes 覆盖**；
- 内嵌运行时可用环境变量控制：
  - `METCOM_ECCODES_DIR`：改用外部 eccodes 目录（如 conda 版）；
  - `METCOM_ECCODES_DISABLE_VENDOR=1`：禁用内嵌运行时（此时 CRA40/CMA-MESO
    直读将失败）；
- `metcom/libs/eccodes-jpeg/eccodes/` 子目录内的 10 个 DLL **不可删减**
  （cffi 依赖解析需要，实测删减会导致 cfgrib 无法注册）。

### 2.4 目录结构

```

├── metcom/                      # 包代码
│   ├── gridgen/                 # 格点文件生成（DEM 裁剪 + 格点文本）

│   │   ├── core.py              #   气压层垂直积分（公式 F0–F14）
│   │   ├── site_retrieval.py    #   站点级反演（4 格点选取 + 双线性插值）
│   │   ├── pipeline.py          #   逐时次/逐站点调度与输出
│   │   ├── readers/             #   各数据源读取器（era5/grib_sources/merra2）
│   │   ├── eccodes_backend.py   #   内嵌 eccodes 运行时注入
│   │   └── grib2nc.py           #   GRIB→NC 离线转换（可选回退）

├── tests/                       # 单元 + 回归测试（pytest）
```

## 3. 配置系统总则

原 MATLAB App 界面上的每个参数，都对应配置文件中的一个键。

### 3.1 配置文件命名规范

```
configs/metcom_<模块名称>.yaml
```

| 配置文件                           | 对应原 MATLAB 模块 / App                        |
| ---------------------------------- | ----------------------------------------------- |
| `configs/metcom_gridgen.yaml`    | `01_MakeGrdText`（两个脚本）                  |
| `configs/metcom_downloader.yaml` | `02_Downloader` 下载脚本"用户配置区"          |
| `configs/metcom_era5.yaml`       | `03_DataProcessing/METCOM_ERA5`（ERA5.mlapp） |
| `configs/metcom_cmameso.yaml`    | `METCOM_CMAMESO`（CMAMESO.mlapp）             |
| `configs/metcom_cra40.yaml`      | `METCOM_CRA40`（CRA40.mlapp）                 |
| `configs/metcom_crav15.yaml`     | `METCOM_CRAV15`（CRAV15.mlapp）               |
| `configs/metcom_merra2.yaml`     | `METCOM_MERRA2`（MERRA2.mlapp）               |
| `configs/metcom_timeinterp.yaml` | `04_TimeInter/main.m`                         |
| `configs/metcom_evaluation.yaml` | `05` 评估脚本 ×2                             |
| `configs/metcom_plot.yaml`       | `05` 绘图脚本 ×3                             |

### 3.2 参数优先级

```
命令行参数  >  配置文件  >  代码内置默认值（取自原 MATLAB App 初始值）
```

即：只想临时改一两个参数时，不必改配置文件，直接在命令行覆盖即可。

### 3.3 路径解析规则

- 相对路径相对于**运行命令时的工作目录**（建议统一在 `METCOM_ver3.1_python`
  根目录下运行）；
- 建议路径分隔符使用 `/`（Windows 下亦适用）。

### 3.4 运行方式

```bash
# 方式一：安装后使用 metcom 命令
metcom retrieve --config configs/metcom_era5.yaml

# 方式二：不安装，直接用模块入口（两者完全等价）
python -m metcom.cli retrieve --config configs/metcom_era5.yaml

# 查看任一子命令的全部可覆盖参数
metcom retrieve --help
```

## 4. 第01步：格点文件生成（gridgen）

**功能**：从全球地形数据（0.05° GMT netCDF）结合中国行政区划边界，生成指定
区域的 DEM NetCDF（步骤 1A），并基于 EGM2008 大地水准面模型输出格点坐标
文本（步骤 1B），支持正高与椭球高两种高程系统。

**配置文件**：`configs/metcom_gridgen.yaml`（`dem:` 与 `stations:` 两节）

### 4.1 步骤 1A：DEM 区域裁剪

| 配置键             | 说明                                                                                                | 默认值                                                                             |
| ------------------ | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `dem.dem_path`   | 全球地形数据（原软件包 lib/ 提供）                                                                  | `../METCOM_ver3.1/01_MakeGrdText/lib/earth_relief_03m.nc`                        |
| `dem.city_shp`   | 中国行政区划 shapefile（`ct_adcode` 字段）                                                        | `../METCOM_ver3.1/01_MakeGrdText/lib/ChinaAdminDivisonSHP/District/district.shp` |
| `dem.output_dir` | DEM NC 输出目录                                                                                     | `DEM_Output`                                                                     |
| `dem.resolution` | 目标格点分辨率（度），支持 0.125/0.25 及整数倍                                                      | `0.125`                                                                          |
| `dem.regions`    | 区域列表，每项含`name`/`extent`/`prefixes`/`is_province_level`/`apply_mask`/`file_name` | 北京（掩膜）、京津冀（掩膜）、京津冀（矩形）                                       |

区域配置示例（与原 MATLAB `regions{}` 一一对应）：

```yaml
- name: "BJ"                          # 区域名（仅日志用）
  extent: [115.5, 117.5, 39.0, 42.0]  # [最小经度, 最大经度, 最小纬度, 最大纬度]
  prefixes: ["11"]                    # 行政区划编码前缀；北京=11
  is_province_level: true             # true=按前 2 位匹配省级编码
  apply_mask: true                    # true=行政掩膜；false=经纬度矩形
  file_name: "bj_dem_0125deg_admin.nc"
```

全国省级行政区编码：北京 11、天津 12、河北 13、山西 14、内蒙古 15、
辽宁 21、吉林 22、黑龙江 23、上海 31、江苏 32、浙江 33、安徽 34、福建 35、
江西 36、山东 37、河南 41、湖北 42、湖南 43、广东 44、广西 45、海南 46、
重庆 50、四川 51、贵州 52、云南 53、西藏 54、陕西 61、甘肃 62、青海 63、
宁夏 64、新疆 65、台湾 71、香港 81、澳门 82。

### 4.2 步骤 1B：格点坐标文本生成

| 配置键                                 | 说明                                                            | 默认值                                  |
| -------------------------------------- | --------------------------------------------------------------- | --------------------------------------- |
| `stations.dem_file`                  | 上一步输出的 DEM 文件                                           | `DEM_Output/bth_dem_0125deg_admin.nc` |
| `stations.output_prefix`             | 输出文件名前缀                                                  | `bth`                                 |
| `stations.base_resolution`           | 输入 DEM 的基础分辨率（度）                                     | `0.125`                               |
| `stations.output_resolution`         | 输出分辨率（须为基础分辨率整数倍）                              | `0.125`                               |
| `stations.output_dir`                | 格点 txt 输出目录                                               | `staList_Output`                      |
| `stations.max_stations`              | 最大站点数限制                                                  | `25000`                               |
| `stations.egm_coarse` / `egm_fine` | EGM2008 格网文本（0.25°/0.125°；≥0.25 用 coarse，否则 fine） | 原软件包 lib/ 路径                      |

### 4.3 运行与输出

```bash
metcom gridgen --config configs/metcom_gridgen.yaml
```

输出（步骤 1A）：`DEM_Output/<区域>.nc`（变量 lon/lat/elevation，CF-1.6）；
输出（步骤 1B）：`staList_Output/<前缀>_<分辨率>_orthometric.txt`（正高，**第
03 步统一使用此文件**）与 `..._ellipsoidal.txt`（椭球高，参考用）。

格点 txt 格式（四列，右对齐）：

```
A000    36.125000   114.625000     61.500
A001    36.125000   115.000000     51.500
```

> 若已有其他格式的站点列表，请转换为上述四列格式后使用。

## 5. 第02步：再分析数据下载（download）

**功能**：从 ECMWF CDS 平台批量下载 ERA5 全球气压层再分析数据（1h、0.25°、
37 层，变量 z/t/q/r），支持多进程并行、IDM 加速、断点续传与自动重试。

**配置文件**：`configs/metcom_downloader.yaml`

| 配置键                                     | 说明                                       | 默认值                      |
| ------------------------------------------ | ------------------------------------------ | --------------------------- |
| `cdsapirc_path`                          | CDS API 密钥文件（`url:`/`key:` 两行） | `CDSAPI/.cdsapirc_test`   |
| `start_time` / `end_time`              | 下载时间范围（YYYYMMDDHH）                 | 示例值，**须修改**    |
| `format`                                 | `nc` 或 `grib`                         | `nc`                      |
| `output_dir`                             | 保存目录（按 yyyyMMdd 日子文件夹组织）     | `ERA5_Download/era5_Data` |
| `use_idm`                                | 是否用 IDM 加速（仅 Windows）              | `false`                   |
| `idm_path`                               | IDM 可执行文件路径（use_idm 时必须）       | 示例路径                    |
| `download_workers`                       | 并发下载进程数（建议 ≤4）                 | `4`                       |
| `min_file_size_mb`                       | 完整文件判定阈值（MB，不完整即删除重下）   | `220`                     |
| `request_retries` / `download_retries` | 请求/下载最大重试次数                      | `3` / `5`               |

### 5.1 CDS API 密钥配置

1. 注册 [https://cds.climate.copernicus.eu/](https://cds.climate.copernicus.eu/)
   （建议 Google 账号，审核较快）；
2. 在个人页获取 **Personal Access Token**；
3. 写入密钥文件（模板 `CDSAPI/.cdsapirc_test` 可复制）：

```ini
url: https://cds.climate.copernicus.eu/api
key: <你的 Personal Access Token>
```

### 5.2 运行与产出

```bash
metcom download --config configs/metcom_downloader.yaml
# 命令行覆盖示例：
metcom download -c configs/metcom_downloader.yaml --start 2024010100 --end 2024010123
```

产出：`{output_dir}/yyyyMMdd/era5_global_qrzt_YYYYMMDDHH.nc`（单时次全球约
220~300 MB），日志 `download_era5.log`。下载的时间范围建议每次不超过 3~5 天，
CDS 请求排队高峰期可能等待数分钟至数小时。

## 6. 第03步：核心 ZTD/PWV 反演（retrieve）

**功能**：选择一种再分析数据，逐时次读取气象场，经 4 邻近格点选取、
位势高→椭球高→正高高程链、气压层垂直积分（Magnus 水汽压、加权平均温度
Tm、折射率积分 + Saastamoinen 顶层修正、PWV 比湿积分）与双线性插值，
反演每个格点/站点的 ZTD、ZWD、ZHD、PWV、Ps、Tm、水汽压、WVD。

**配置文件**：每个数据源一个（对应原 5 个 MATLAB App）

| 配置键                        | 原 GUI 字段        | 说明                                            |
| ----------------------------- | ------------------ | ----------------------------------------------- |
| `data_path`                 | Data Path          | 数据根目录（见 6.1 目录约定）                   |
| `output_path`               | Output Path        | 反演结果输出目录                                |
| `output_format`             | OutPut Type        | `txt`（推荐）/ `mat` / `dat`              |
| `site_file`                 | Stations List      | 站点文件（正高，四列格式）                      |
| `start_time` / `end_time` | Start/End time     | `YYYYMMDD` 或 `YYYYMMDDHH`                  |
| `spatial_resolution`        | Spatial resolution | [纬度, 经度]，须与数据一致                      |
| `time_resolution`           | Time resolution    | 1h / 3h / 6h，须与数据一致                      |
| `parallel`                  | Parallel pool      | 站点级并行（joblib），默认 false                |
| `n_jobs`                    | —                 | 并行进程数（parallel: true 时生效）             |
| `egm_file`                  | （隐式）           | EGM2008 改正文件；null = 自动定位原软件包内文件 |
| `grib2.enabled` 等          | （原 exe 转换）    | 可选回退，见 6.2                                |

### 6.1 数据目录约定

| 数据源   | 目录结构                       | 文件命名                                                                 |
| -------- | ------------------------------ | ------------------------------------------------------------------------ |
| ERA5     | `data_path/yyyyMMdd/*.nc`    | `era5_global_qrzt_YYYYMMDDHH.nc`                                       |
| CMA-MESO | `data_path/yyyyMMdd/*.grib2` | `GRAPES3KMORIG_(GPH\|RHU\|TEM)_100_YYYYMMDDHH_CHN_0_0.grib2`             |
| CRA40    | `data_path/yyyyMMdd/*.grib2` | `CRA40_(GPH\|RHU\|SHU\|TEM)_YYYYMMDDHH_GLB_0P25_HOUR_V1_0_0.grib2`        |
| CRA V1.5 | `data_path/yyyyMMdd/*.grib2` | `ART_ATM_GLB_0P10_6HOR_ANAL_YYYYMMDDHH_版本号_(HGT\|RH\|SPFH\|TMP).grib2` |
| MERRA2   | `data_path/yyyy/*.nc`        | `MERRA2_400.inst6_3d_ana_Np.YYYYMMDD.SUB.nc`（一天一文件，含 4 时次）  |

说明：

- NC 与 GRIB2 可混合存放，读取器按时间戳自动配对各变量文件；
- 文件名须严格符合上述模式（读取器按正则配对），不符合的文件会被跳过并警告；
- 五种数据的气压层顺序、缺测值（FillValue→NaN→MERRA2 地下层修剪）均按
  MATLAB 版相同方式处理。

### 6.2 GRIB 直读与可选回退

- **默认直读**：三种 GRIB2 数据源由包内内嵌 eccodes 运行时直接解码
  （见 2.3 节），无需任何预转换；
- 可选回退：如需 NC 中间产物，可在配置中设 `grib2.enabled: true`（配
  `grib2.raw_path` 原始 GRIB 目录与 `grib2.temp_dir` 转换输出目录），或直接
  使用原版 `GribToNcConverter_cfgrib.exe` 转换后把 `data_path` 指向 NC 目录。

### 6.3 运行与输出

```bash
# 按配置文件运行（数据源从文件名 metcom_<源>.yaml 自动推断）
metcom retrieve -c configs/metcom_era5.yaml

# 命令行覆盖示例
metcom retrieve -s era5 -c configs/metcom_era5.yaml \
    --start 2024010100 --end 2024010123 \
    --site-file benchmarks/bth_0125_orthometric.txt \
    --output-path output_ERA5

# 站点级并行
metcom retrieve -c configs/metcom_era5.yaml --parallel --n-jobs 8
```

输出：`{output_path}/{年积日}/ztd_{YYYYMMDDHH}_sit_{数据源}.{txt|dat|mat}`，
例如 `output_ERA5/2024001/ztd_2024010100_sit_era5.txt`。年积日为
`年+三位天数`（如 2024-06-01 → 2024153，闰年；非闰年 2025-06-01 → 2025152）。

文件内容（12 列，首行表头）：

```
name    latitude  longitude  height(m)  ZTD(m)  ZHD(m)  ZWD(m)  PWV(m)  Ps(hpa)  Tm(K)  vapor_pressure(hpa)  WVD
A000         ...        ...        ...     ...     ...     ...     ...     ...    ...                  ...   ...
```

| 列                       | 含义             | 单位                 |
| ------------------------ | ---------------- | -------------------- |
| name                     | 站点名           | —                   |
| latitude / longitude     | 纬度 / 经度      | °                   |
| height(m)                | 站点正高         | m                    |
| ZTD(m) / ZHD(m) / ZWD(m) | 天顶总/干/湿延迟 | m（典型 2.3~2.5）    |
| PWV(m)                   | 大气可降水量     | m（典型 0.005~0.08） |
| Ps(hpa)                  | 站点气压         | hPa                  |
| Tm(K)                    | 加权平均温度     | K                    |
| vapor_pressure(hpa)      | 水汽压           | hPa                  |
| WVD                      | 水汽密度         | g/m³                |

评估阶段会自动把 ZTD/PWV 乘 1000 转为 mm。

> **性能提示**：单时次全球场约 1~5 GB，逐时次读取为主要耗时（每个时次数十
> 秒，视磁盘而定）。大量站点时可开 `parallel: true`；内存紧张时保持串行。

---

## 7. 第04步：时间维度插值（timeinterp）

**功能**：把低时间分辨率的反演结果（如 MERRA2 的 6h）插值到逐小时。采用
not-a-knot 三次样条外推（与 MATLAB `interp1 'spline','extrap'` 一致），异常
时回退线性外推；自动跨天扩展（复制次日 00 时为当日 24 时，处理后删除临时
文件）。

**配置文件**：`configs/metcom_timeinterp.yaml`

| 配置键                | 说明                                                         | 默认值                                   |
| --------------------- | ------------------------------------------------------------ | ---------------------------------------- |
| `input_dir`         | 待插值的反演结果目录（含`20*` 年积日子文件夹）             | `output_Merra2`                        |
| `output_dir`        | 插值结果输出目录                                             | `TimeInter_MERRA2`                     |
| `original_interval` | 原始时间分辨率（小时）——仅作文档，不参与计算（与原版一致） | `6`                                    |
| `target_interval`   | 目标时间分辨率（小时）                                       | `1`                                    |
| `variables`         | 插值变量列表                                                 | ZTD/ZHD/ZWD/PWV/Ps/Tm/vapor_pressure/WVD |

```bash
metcom timeinterp -c configs/metcom_timeinterp.yaml
```

输出：每天 `0..24` 时（有跨天扩展）或 `0..当日最晚时次` 的逐小时文件，命名与
输入一致。样条要求某变量当日有效点 ≥2，否则该变量整列输出 NaN。

## 8. 第05步：精度评估与可视化（evaluate / plot）

**功能**：将反演结果（数据源 A）与参考数据（数据源 B，如武大 GMET 的 ERA5
结果）按时次/站点对齐，计算 Bias/RMSE（ZTD、PWV 自动 m→mm），并绘制时序图
与空间热力图。

### 8.1 精度评估（evaluate）

**配置文件**：`configs/metcom_evaluation.yaml`

| 配置键                 | 说明                                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------------------------- |
| `dir_a` / `name_a` | 数据源 A 目录（反演结果）与名称                                                                               |
| `dir_b` / `name_b` | 数据源 B 目录（参考数据，如`../SOMEDATA/ERA5_GMET_BTH_Results`）与名称                                      |
| `time_input`         | 时间范围`"YYYYMMDDHH,YYYYMMDDHH"`                                                                           |
| `eval_mode`          | `timeseries`（逐时刻全体站平均，对应 compareByTime_Grid）或 `bystation`（逐站全时段，对应 compareByGrid） |
| `eval_vars`          | 评估变量（原始列名，如`ZTD(m)`、`PWV(m)`）                                                                |
| `var_config`         | 变量换算配置（可选，默认 ZTD/PWV ×1000 → mm）                                                               |
| `output_dir`         | 评估结果输出目录                                                                                              |
| `output_tag`         | 输出文件名标签（默认`NAME_A_vs_NAME_B`）                                                                    |

```bash
metcom evaluate -c configs/metcom_evaluation.yaml --mode timeseries
metcom evaluate -c configs/metcom_evaluation.yaml --mode bystation
```

输出：`{tag}_Timeseries_{时段}.csv/.txt` 或 `{tag}_ByStation_{时段}.csv/.txt`
（列结构与 MATLAB 版一致；Time 列为 YYYYMMDDHH）。

> 数据源 A/B 的文件须按 `20*` 年积日子文件夹组织，文件名
> `ztd_YYYYMMDDHH_sit_源名`（`.txt` 后缀可有可无）。

### 8.2 可视化绘图（plot）

**配置文件**：`configs/metcom_plot.yaml`

| 配置键                               | 说明                                                                                                            |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| `plot_type`                        | `sequence`（RMSE 时序图+直方图）/ `heatmap_rmse`（站点 RMSE 热力图）/ `heatmap_value`（单时刻数值热力图） |
| `txt_file`                         | 输入文件（按 plot_type 指向对应评估/反演结果）                                                                  |
| `output_dir`                       | 图片输出目录                                                                                                    |
| `name_a` / `name_b` / `region` | 图名要素；`region`: `BTH`（京津冀）或 `CHN`（全国）                                                       |
| `plot_vars`                        | 绘图变量（与输入文件列名一致，如`ZTD_RMSE(mm)`）                                                              |
| `var_convert`                      | heatmap_value 的单位换算（如`ZTD(m): 1000`）                                                                  |
| `china_shp`                        | 行政区划 shapefile（掩膜轮廓）                                                                                  |
| `grid_resolution`                  | 热力图插值分辨率（像素网格数，默认 80）                                                                         |

```bash
metcom plot -c configs/metcom_plot.yaml
```

依赖 `matplotlib` + `cartopy` + `geopandas`（绘图功能可选安装）。输出 300dpi
PNG，命名与原版一致（如 `MERRA2_vs_ERA5_GMET_BTH_Timeseries.png`）。

## 9. 输出文件格式说明

### 9.1 反演结果（.txt / .dat / .mat）

- 逐时次一个文件：`ztd_{YYYYMMDDHH}_sit_{源名}.{扩展名}`，位于
  `{output_path}/{年积日}/` 下；
- txt/dat：首行 12 列表头（列宽 `%4s` + 每列 20 字符），数据行 8 位小数，
  缺测输出 `NaN`；
- mat：struct 变量 `Result_<源名>`，字段
  `name/latitude/longitude/height_m/ZTD_m/ZHD_m/ZWD_m/PWV_m/Ps_hpa/Tm_K/ vapor_pressure_hpa/WVD`（与 saveToMat 一致）。

### 9.2 评估结果

- Timeseries CSV：`Time,N,ZTD_Bias(mm),ZTD_RMSE(mm),PWV_Bias(mm),PWV_RMSE(mm)`；
- ByStation CSV：`SITE,LAT/deg,LON/deg,ALT/m,Time_Range,N,ZTD_RMSE(mm), ZTD_Bias(mm),PWV_RMSE(mm),PWV_Bias(mm)`；
- TXT 为右对齐 15 字符宽表格（Timeseries 另含中文汇总头），与原版格式一致，
  绘图脚本兼容解析。

## 10. 从零开始的完整流程

```
第 1 步  准备站点列表
├── 编辑 configs/metcom_gridgen.yaml（区域、分辨率）
├── metcom gridgen -c configs/metcom_gridgen.yaml
└── 得到 staList_Output/*_orthometric.txt（第 03 步统一用正高文件）

第 2 步  下载 ERA5 数据（如用其他数据源则从网盘/业务渠道获取，见各 readme）
├── 配置 CDS API 密钥
├── 编辑 configs/metcom_downloader.yaml（时间范围建议 3~5 天内）
└── metcom download -c configs/metcom_downloader.yaml

第 3 步  反演 ZTD/PWV（每种数据源一个配置文件）
├── 编辑 configs/metcom_<源>.yaml（data_path / site_file / 时间范围）

第 4 步（可选）时间插值

第 5 步  精度评估与可视化
├── 编辑 configs/metcom_evaluation.yaml（dir_a/dir_b/时间范围）

├── metcom evaluate -c configs/metcom_evaluation.yaml --mode bystation
└── metcom plot -c configs/metcom_plot.yaml
```

## 11. 常见问题与注意事项

**Q1：GRIB2 直读报 `FunctionalityNotEnabledError`？**
当前 eccodes 缺 JPEG2000 解码器。检查包内 `metcom/libs/eccodes-jpeg/` 是否
完整（勿删 `eccodes/` 子目录内的 DLL），确认未设置
`METCOM_ECCODES_DISABLE_VENDOR=1`；或改用原版 exe 预转换 NC。

**Q2：反演提示"未处理任何时次"？**
检查 `data_path` 下的文件命名是否符合 6.1 节约定、时间范围是否与数据匹配、
`--source`/配置文件名对应的数据源是否正确。

**Q3：提示"Latitude/Longitude value is out of the range"？**
站点坐标超出该数据覆盖范围（CMA-MESO 为中国区域 10~60°N / 70~145°E）；
站点经度须用 -180~180（不是 0~360）。

**Q4：站点高度高于最高气压层报错？**
站点海拔超过了数据的最高气压层高度（如 ERA5 顶层 1 hPa ≈ 48 km），正常数据
不会触发；原 MATLAB 在同一情形下会直接崩溃。

**Q5：MERRA2 输出是 6 小时分辨率，怎么变成逐小时？**
用第 04 步：`metcom timeinterp`（`target_interval: 1`）。

**Q6：处理大量格点（如 1400+ 站）速度慢？**
正常现象：每站需 4 格点 × 数十气压层的垂直积分。单时次主要耗时在读盘。
可 `--parallel --n-jobs 8`（内存充足时），或先用小站点文件验证流程。

**Q7：PWV 数值看起来很小？**
PWV 单位为米，典型 0.005~0.08 m；评估阶段自动 ×1000 变 mm。

**Q8：评估报"无有效匹配数据"？**
检查 `dir_b`（GMET 参考数据）是否按 `20*` 年积日子文件夹组织、文件命名是否
为 `ztd_YYYYMMDDHH_sit_*`、`time_input` 是否与数据重叠。

**Q9：绘图报 cartopy/geopandas 相关错误？**
绘图依赖为可选安装：`pip install matplotlib cartopy geopandas`。热力图依赖
的 `cartopy.mpl.patch.geos_to_path` 在 cartopy 0.23.0 验证可用，若未来版本
移除请锁定版本。

**Q10：CDS 下载很慢或排队？**
高峰期属正常（数分钟至数小时）；建议 Google 账号注册的 API；每次时间范围
3~5 天内；`use_idm: true` 可用 IDM 加速（仅 Windows）。

## 12. 与 MATLAB 版的差异

- **交互**：5 个 .mlapp 图形界面 → 10 个 `metcom_*.yaml` 配置文件 + 命令行，
  配置键与原 GUI 字段一一对应（各配置文件内有注释对照）；
- **GRIB 处理**：原"exe 预转换 → MATLAB 读 NC" → Python 直读 GRIB（内嵌
  eccodes 运行时），预转换保留为可选回退；
- **性能**：位势高换算按"每时次一次"缓存（原版逐站点重复计算，这是原版
  "1312 站很慢"的主因），结果数值完全一致；
- **崩溃性 bug 已修复并记录**：站点高于最高气压层、评估脚本静默吞异常、
  下载脚本裸 `except` 等，完整清单见 `docs/porting_notes.md`；
- **数值等价性**：以 MATLAB 输出为基准的端到端回归——五种数据源反演
  逐位一致或机器精度（3.8e-11），评估 CSV 逐位一致，01 模块输出逐字节一致；
- 原版算法细节（如 PWV 积分与外推分支所用 g 值不同、ZHD 每层加
  Saastamoinen 顶层修正等）**原样保留**，以保证数值对齐。
